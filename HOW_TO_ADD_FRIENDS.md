### ❓ How to find this data yourself?

When running the local blockchain (`npx hardhat node`), it lists 20 test accounts.
*   **Account #0** is usually YOU (the one deploying).
*   **Account #1 to #19** can be used as friends.

To use them as real users (to chat back and forth):
1.  **Import Account**: Open MetaMask -> Click Circle Icon -> "Import Account" -> Paste **Private Key** from the terminal.
2.  **Switch Account**: In MetaMask, switch to the imported account.
3.  **Register**: Refresh the app and create an account for this new user.
